2.4 na.action = na.method(y = , x = ) 详解已修正

① 响应变量：y = "include"（默认）/ "omit" / "fail"

include：保留 y 为 NA 的行（不贡献似然），以下场景应使用：

  • 规则网格空间分析（ar1(Row):ar1(Col)）：删除缺失小区会破坏网格。
  • 多性状 cbind(t1, t2)：只缺一个性状的个体仍保留其他性状信息。
  • 交叉验证掩码：验证集 y 置 NA 后需保留其行，以便直接按行对齐预测值。

注：无表型个体只要出现在 ainv / ginv / hinv 的 rowNames 中，vm() 就会给出其 BLUP，与 y 的设置无关。

omit：删除 y 为 NA 的行；仅适用于无网格要求的单性状模型。

② 解释变量：x = "fail"（默认）/ "include" / "omit"

fail（默认）：固定或随机项中出现 NA 时报错停止，提醒你主动处理。

include：协变量 NA 按 0 处理（⚠️ 先中心化 scale(x, scale = FALSE)，让 0 等于均值）；因子 NA 在设计矩阵中该行全为 0。

omit：删除任一解释变量为 NA 的整行。

3B 方差固定 ("F") 与等式约束 (vcc)

3.3 何时需要固定方差

  1. 常规育种值评估：参数已由大样本估计，全部设 "F" 并 maxit = 1，直接解 MME 得 BLUP 与 SE。
  2. 两阶段 MET / Meta 加权：二阶段用 weights = 1/SE²，并把 units!R 固定为 1，使误差方差等于一阶段已知值。
  3. LRT 检验特定假设：如固定 CovA = 0，或检验 rg = 1（边界检验）。
  4. 多性状逐步收敛：先用单性状方差固定对角线，只估协方差，收敛后再放开为 "P" 联合估计。
  5. GWAS 快速扫描 (P3D / EMMAX)：零模型估一次 σ²ₐ、σ²ₑ，扫描时固定。

4.2 Wald 检验与 LRT已修正

  • Wald：默认 ssType = "incremental"（序贯）；不平衡数据用 "conditional"。denDF = "default" 优先代数法，失败时用数值法。
  • LRT：嵌套模型且固定效应完全相同；方差 = 0 在参数边界上，用混合 χ²。
Wald 与 LRT
# 条件 F 检验 + 近似分母自由度
wald.asreml(mod, ssType = "conditional", denDF = "default")

# 随机效应 LRT (方差在边界 0 上)
lrt.asreml(mod_full, mod_reduced, boundary = TRUE)

# 手算 (单个方差组分, 边界修正 0.5χ²0 + 0.5χ²1)
D <- 2 * (mod_full$loglik - mod_reduced$loglik)
p_boundary <- 0.5 * (1 - pchisq(D, df = 1))
p_interior <- 1 - pchisq(D, df = 1)  # 协方差/相关等非边界参数

动物模型进阶：重复力、母体效应、多性状与遗传相关

WAM 教程 v4 写法

6.1 个体动物模型 vs 重复力模型 已修正vm(Animal, ainv) + ide(Animal)

模型：y = Xb + Z₁a + Z₂pe + e，a ~ N(0, Aσ²ₐ)，pe ~ N(0, Iσ²ₚₑ)。

要点：有重复记录却只拟合 vm() 时，σ²ₚₑ 会并入 σ²ₐ，遗传力被严重高估（Cookbook 案例 10：0.636 → 0.026）。

三步对比

                residual = ~ idv(units), data = dat)

                residual = ~ idv(units), data = dat)

6.2 母体效应模型 M1–M4 已修正str(~ vm(Animal,ainv) + vm(Dam,ainv), …)

模型：y = Xb + Z₁a + Z₂m + Z₃c + e；a 直接加性，m 母体遗传，c 母体永久环境，σam = Cov(a, m)。

Willham (1972) 总遗传力：h²T = (σ²ₐ + 0.5σ²ₘ + 1.5σam) / σ²ₚ，σ²ₚ = σ²ₐ + σ²ₘ + σam + σ²c + σ²ₑ。

Dam 的 ID 须出现在系谱中，否则 vm(Dam, ainv) 报错。

四种递进模型
# M1: Dam 作普通随机因子 (母体总效应, 不分遗传/环境)
m1 <- asreml(bwt ~ 1 + sex, random = ~ vm(Animal, ainv) + Dam,
             residual = ~ idv(units), data = gryphon)

# M2: 直接加性 + 母体遗传, Cov(a,m) = 0

             random = ~ vm(Animal, ainv) + vm(Dam, ainv),
             residual = ~ idv(units), data = gryphon)

m3 <- asreml(bwt ~ 1 + sex,
             random = ~ vm(Animal, ainv) + vm(Dam, ainv) + ide(Dam),
             residual = ~ idv(units), data = gryphon)

# M4: 允许 Cov(a,m) != 0
m4 <- asreml(bwt ~ 1 + sex,
  random = ~ str(~ vm(Animal, ainv) + vm(Dam, ainv),
                 ~ us(2, init = c(1, -0.1, 0.5)):vm(Animal, ainv)) +
             ide(Dam),

6.4 相关系数与显著性检验us() vs idh() / corgh()

基因 × 环境互作 (G×E) 与 Type-B 遗传相关

CS → corh → corgh / us → fa

7.1 概念与模型选择

Type-B 相关 (Burdon 1977)：同一性状在不同环境间的遗传相关。复合对称模型下 rB = σ²G / (σ²G + σ²GE)。rB → 1 表示排名稳定；经验上 rB < 约 0.67 提示存在较强秩次改变型 G×E，可考虑划分育种区。

设计效应：at(Site):Rep 每地点独立区组方差；at(Site, c("S1","S3")):Block 仅特定地点。

残差：dsum(~ units | Site) 地点异质残差，或 dsum(~ ar1(Row):ar1(Col) | Site) 加空间。

地点数推荐结构
任意，先行CS：vm + Site:vm
任意corh(Site)：异质方差 + 统一相关
≤ 4corgh / us(Site)
≥ 5fa(Site, k)，k 逐步增加按 AIC/LRT 选

7.2 四种递进结构

G×E 模型与 r_B
# 1. 复合对称 (CS): 同质遗传方差、相同两两相关
m_cs <- asreml(yield ~ Site,
  random   = ~ vm(ID, ainv) + Site:vm(ID, ainv) + at(Site):Rep,
  residual = ~ dsum(~ units | Site), data = met_dat)
# 先打印 varcomp 确认 V1 = σ²G, V2 = σ²GE
summary(m_cs)$varcomp
vpredict(m_cs, r_B ~ V1 / (V1 + V2))

# 2. corh: 各地点独立遗传方差 + 统一相关 r_B (直接输出)
m_corh <- asreml(yield ~ Site,
  random   = ~ corh(Site):vm(ID, ainv) + at(Site):Rep,
  residual = ~ dsum(~ units | Site), data = met_dat)
summary(m_corh)$varcomp   # "...!Site!cor" 行即 r_B 及 SE

# 3. corgh: 非结构化相关 (地点少时)
m_corgh <- asreml(yield ~ Site,
  random   = ~ corgh(Site):vm(ID, ainv) + at(Site):Rep,
  residual = ~ dsum(~ ar1(Row):ar1(Col) | Site), data = met_dat)

# 4. 因子分析 FA(2): 地点多时首选，捕获异质性并保证半正定
m_fa2 <- asreml(yield ~ Site,
  random   = ~ fa(Site, 2):vm(ID, ainv) + at(Site):Rep,
  residual = ~ dsum(~ ar1(Row):ar1(Col) | Site), data = met_dat,
  maxit = 50)

9.2 一步法 ssGBLUP 已修正H.inverse(A, Ginv, lambda)

A 与 Ginv 都须为完整方阵，Ginv 的个体须是 A 的子集；建议先将 G 对齐 (align) 到 A₂₂ 再求逆。

library(ASRgenomics); library(AGHmatrix); library(asreml)

data(ped.pine)
A <- AGHmatrix::Amatrix(data = ped.pine)   # n_a x n_a

G <- G.matrix(M_clean, method = "VanRaden")$G

# 1. 检查并匹配 G 与 A
chk <- match.G2A(A = A, G = G, clean = TRUE, ord = TRUE,
                 mism = TRUE, RMdiff = TRUE)

# 2. 将 G 对齐到 A22，再求完整逆

                 align = TRUE, sparseform = FALSE)$Gb
Ginv <- G.inverse(G = G_al, sparseform = FALSE)$Ginv

# 3. 构建 H^-1 (λ 同时设定 τ = ω，范围 0–1)
hinv <- H.inverse(A = A, Ginv = Ginv, lambda = 0.90,

attr(hinv, "INVERSE")   # 应为 TRUE

# 4. 拟合：已测序与未测序个体同时得到 GEBV
ss <- asreml(DBH_Adj ~ 1, random = ~ vm(Genotype, hinv),

9.3 K 折交叉验证与 G.predict()PA · Accuracy · Bias

  • 预测力 PA：r(yval, GEBV)，y 可用观测值或校正表型 y*。
  • 准确性：r(y, GEBV) / √h²（Dekkers 2007），h² 统一用全量数据估计值。
  • 偏差：lm(y_val ~ gebv_val) 的斜率 b₁，理想值 1；b₁ < 1 表示 GEBV 离散度过大（膨胀）。
  • CV1：随机分折（家系内有亲属）；CV2：整家系留出（预测新家系）。
  • G.predict(G, gy)：用多元正态条件分布由已知 BLUP 预测其余个体，gy 须为带行名的矩阵。
掩码 CV 循环 + G.predict

9.4 CV 中是否固定方差组分？ 已修正方法学问答

策略做法评价
1 每折重估（推荐）每折仅用训练集估计方差并预测无数据泄露；论文首选
2 热启动以全量结果作初值，约束仍为 P仍是每折重估，只是收敛更快
3 固定全量方差Constraint = "F" + maxit = 1轻微泄露，小样本或低 h² 时高估 PA；需在论文中说明
关键区分：折内拟合用策略 1；而计算准确性 r/√h² 时，分母统一使用全量数据的 h²full，以便公平比较 ABLUP / GBLUP / ssGBLUP。

  # 策略 3: 固定方差，只解一次 MME
