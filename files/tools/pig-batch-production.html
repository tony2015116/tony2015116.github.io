    母猪场生产参数

    当前模式所在行已高亮。每批配种头数按“各舍在群母猪（含待配返情母猪）平均存栏 = 基础母猪”反推，已包含补入的后备母猪；产床 = 每批分娩窝数 ×（1+冗余），配种栏 = 每批配种数 ×（1+冗余），妊娠栏 = 每批配种数 × 受胎率 ×（1+冗余）。“单元”指同一天全进全出的一组栏舍。PSY 为理论值。

    保育与育肥参数

    每批仔猪按断奶日成批进入保育，再成批转入育肥。单元数 = ⌈(停留天数 + 清洗天数) ÷ B⌉，保育至少清洗 4 天、育肥至少 5 天。“单批栋数”= 每批育肥猪 ÷ 单栋育肥舍容量，≥1 表示每批仔猪可以单一来源整栋全进全出。

    评分为 1–5 分的相对比较，依据本页推导出的单元数、利用率、批量和作业节律，并结合一般生产经验；数值越高代表该维度越有利。点击任一行或卡片可切换模式并回到动画。

    第一性原理推导

    批次生产的全部结构来自三个数：妊娠期 G 约 114 天，是生物学常数；哺乳期 L 是管理决策；断奶到输精间隔 W 经同期化处理后可稳定在约 5 天。三者之和是一头母猪的繁殖周期：

    C = G + L + W = 114 + L + 5

    母猪群要每隔 B 天准时“接力”，周期必须能被批次间隔整除，母猪被分成 n 个固定群：

    C = n × B　　L = 21 → C = 140 = 20 周；L = 28 → C = 147 = 21 周；L = 25 → C = 144

    140 能被 7、14、28、35 整除，147 能被 7、21 整除，所以三周批必须配 28 天断奶，其余周批配 21 天断奶；144 不是 7 的倍数，只能走 18 天或 36 天这类非周批。每栋舍的全进全出单元数由停留天数 D、最短清洗天数 X 与 B 决定：

    单元数 = ⌈(D + X) ÷ B⌉　　利用率 = D ÷ (单元数 × B)

    四周批做了两处调整：产前 3 天进产房（产房停留 24 天，一个单元刚好装下），孕检转栏推迟到配后 30 天（妊娠舍停留 81 天，3 个单元刚好装下）。

    单批作业日程

    以断奶日为 D0。各模式单批日程结构相同，差别在哺乳天数、孕检转栏日和进产房日。

    返情母猪与后备母猪

    • 返情一般出现在配后约 21 天。B 能整除 21（单周批、三周批）时，返情母猪自然发情日就是某一批的输精日，直接随批配种。
    • 返情时母猪刚排卵，随后约 16 天处于黄体期，烯丙孕素只能推迟发情、不能提前，所以返情母猪最早在配后约 42 天（第二个情期）才能再配。二周批的 42 天正好是 3 个批次，自然随批；四周批、五周批、18 天批、36 天批要在待配栏饲喂烯丙孕素，分别并入配后第 56、70、54、72 天的那一批，停药日 ≈ 目标输精日 − 6 天。用药剂量与疗程请由兽医确定。
    • 后备母猪在目标批次断奶日前约 21 天进入待配栏，饲喂烯丙孕素同期，与断奶母猪同日输精。每批补入后备数 = 淘汰数 + 妊娠期损失数，使每批配种头数保持稳定。

    母猪场每日用工曲线

    按稳定生产期的期望头数，把各项作业工时摊到每一天并叠加，展示一个完整繁殖周期。只计母猪场（配种、妊娠、产房），不含保育育肥。工时系数为估算默认值，请按本场实测修改。

    其他固定系数：同期化注射 0.02 时/头·次；查返情 0.01 时/头·天；孕检 0.03 时/头；转群 0.06–0.08 时/头；断奶仔猪转出 0.01 时/头；仔猪处理 0.4 时/窝；产房清洗 1.0 时/床，配怀栏清洗 0.15 时/栏，分 3 天完成。

    全年作业日历

    以第 1 群断奶日为起点，排出之后 365 天的关键作业。周末和法定节假日（元旦、春节、劳动节、国庆，按近似日期标注，以当年公布为准）上的作业会高亮。头数为按场景参数计算的期望值。

    自定义批次模式

    设定批次间隔和各阶段天数，页面检验繁殖周期能否被批次间隔整除，并推导单元数。通过后可加入模式列表，在动画、参数和用工页中使用。

    按现有栋舍反推

    输入现有产房和配怀舍条件，判断各批次模式能支撑多少基础母猪、目标存栏（场景参数）是否可行、缺多少栏位。产房按“整间”分配到单元，房间数除不尽的部分会闲置；配怀舍需要能分隔出足够的全进全出单元。

    从连续生产转为批次生产的过渡方案

    连续生产中，母猪的断奶日均匀分布在每一天。转批时，每头母猪在断奶时被归入最近的一个批次：离批次断奶日在“哺乳期可调范围”内的，通过提前或推迟断奶对齐；其余的断奶后饲喂烯丙孕素，等到下一个批次再同期发情。已怀孕的母猪无法调整，要等它们分娩断奶后才能归批，所以过渡期约为一个繁殖周期。
