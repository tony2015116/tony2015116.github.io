数量遗传学 · BLUP 育种值估计

育种动物模型图鉴

P=A+D+I+E+e

从这条“全面模型”出发：表型被拆成加性、显性、上位、环境和随机残差五块。各种动物模型的区别，就在于它们把哪几块单独拿出来估计，又把哪几块并进了残差。

00先对齐概念

这里的“动物模型”指动物育种中估计育种值（EBV）的线性混合模型，不是医学实验里的小鼠模型。之所以叫“动物”模型，是因为模型里每一头动物（有没有自己的记录都算）都有一个属于自己的遗传效应，并通过亲缘关系互相“借信息”。

它要回答的问题很朴素：一头猪长得快，到底是因为基因好，还是因为吃得好、栏舍好、运气好？基因里还要再分：哪部分能稳定遗传给后代，哪部分只在特定配对时才出现。

01全面模型：表型的完整拆解

P表型值 Phenotype实际测到的数：日增重、产仔数、背膘厚观测值 y
A加性效应（育种值）每个等位基因效应的简单累加。父母各传一半，能稳定遗传用于选种
D显性效应同一位点两个等位基因的“搭配效果”，如 Aa 不等于 AA 和 aa 的平均。每代重新组合，不能直接遗传用于选配、杂交
I上位效应不同位点基因之间的互作，一个基因的作用要看另一个基因的“脸色”。减数分裂时会被重组打散用于选配、配套系
E环境效应可识别的系统环境：营养、栏舍、温湿度、光照、季节、母亲的哺育，以及基因与环境的互作 G×E用于环境调控
e随机残差无法识别、也无法重复的偶然因素，如测量误差、某天打架受伤无法利用

对应的方差分解

如果各部分互不相关，表型方差也能相加：

σ²P = σ²A + σ²D + σ²I + σ²E + σ²e
h² = σ²A / σ²P狭义遗传力：选种能利用的比例，决定选择反应
H² = σ²G / σ²P广义遗传力，σ²G = σ²A + σ²D + σ²I：基因的全部贡献，含不能稳定遗传的部分
σ²I = σ²AA + σ²AD + σ²DD + …上位方差还能细分为加×加、加×显、显×显等

动手感受：方差构成决定育种策略

A D I E e
0.30狭义遗传力 h²
0.45广义遗传力 H²
0.15非加性占比 (D+I)/P
0.25可调控环境占比 E/P

三条育种路径

1. 选种 · A只有加性效应能稳定遗传，挑育种值高的种猪留种，好基因一代代累积。育种核心：积累加性效应
2. 选配 · D + I显性和上位效应取决于“谁配谁”。通过杂交、配套系和选配方案，让下一代拿到好的基因组合，这就是杂种优势的来源。杂交利用：优化基因组合
3. 环境 · E营养是核心，温湿度、光照、空气质量也会影响基因的表达和肠道菌群。不同基因型适合的环境还可能不同（G×E）。环境调控：影响表型表达

写成混合模型

把上面的公式写成矩阵形式，每个随机效应配一个“个体之间有多像”的协方差矩阵：

y = Xb + Za + Zd + Zi + Wc + e
a ~ N(0, Aσ²A)　　谱系加性关系
d ~ N(0, Dσ²D)　　显性关系
i ~ N(0, (A⊙A)σ²AA + (A⊙D)σ²AD + (D⊙D)σ²DD)
c ~ N(0, Iσ²c)　　永久环境 / 窝 / 母体环境
e ~ N(0, Iσ²e)

⊙ 是哈达玛积（矩阵对应元素相乘）。图中的 E 在模型里分成两部分：可列举的环境分组（场、年、季、栏、营养方案）放进固定效应 Xb；跟着个体、窝或母亲走的环境放进随机效应 c。

这是“理论上的全面模型”。实际中几乎不会把所有项一次全估：显性和上位方差需要大量全同胞、近交个体或基因组数据才能分开，否则会混进残差或被加性效应“吸走”。于是有了下面各种取舍不同的模型。

02基本动物模型：只单独估计 A

y = Xb + Za + e
y观测值向量：每条记录，如达 100 kg 日龄
b · X固定效应及其关联矩阵：场、年、季、性别、批次
a · Z加性遗传效应（育种值）及其关联矩阵，Z 把记录对应到动物
e残差。在这个模型里，D、I 和随机环境都被并进了 e

换成学生考试的比喻：

成绩 y卷面分
固定效应 Xb哪个学校、哪年的卷子难
育种值 Za能传给孩子的“天赋”
残差 e当天状态、蒙对几题

模型背后的假设

  • a ~ N(0, Aσ²ₐ)育种值服从正态分布，个体间协方差由亲缘关系矩阵 A 决定：亲缘越近，育种值越像。
  • e ~ N(0, Iσ²ₑ)残差相互独立、方差相同。若 D、I 很大却被并进 e，这条假设会被破坏，因为全同胞之间的残差其实相关。
  • Cov(a, e) = 0基因和偶然环境不相关，例如不会刻意把好基因的猪放进好栏舍。
  • 无穷小模型性状由大量微效基因加性控制，所以育种值近似正态。
  • 方差组分已知实际先用 REML 估出方差组分，再代入混合模型方程求 BLUP。

A 矩阵读法：亲子之间是 0.5；对角线是 1 + F，个体 4 的近交系数 F = 0.25，所以是 1.25。规则只有两条：aᵢⱼ = ½(aᵢ,父 + aᵢ,母)，aᵢᵢ = 1 + ½·a父,母。

显性效应要看两个等位基因同时相同的概率，所以用另一套矩阵 D：dᵢⱼ = ¼(a父ᵢ,父ⱼ·a母ᵢ,母ⱼ + a父ᵢ,母ⱼ·a母ᵢ,父ⱼ)。上位效应则用 A、D 的哈达玛积近似。不同亲属在各类效应上的“相似度”如下：

亲属关系（非近交）加性 A显性 D加×加 A⊙A显×显 D⊙D
同一个体1111
亲子0.500.250
全同胞0.50.250.250.0625
半同胞0.2500.06250
祖孙0.2500.06250

表里能看出一个关键事实：亲子间的显性相似度是 0，父母传给后代的只是单个等位基因，而不是“搭配”。所以显性效应不能靠选种传下去；只有全同胞这类两边都共享的亲属，才会在显性上相似。要估 σ²D，数据里必须有足够多的全同胞。

04动手感受：遗传力决定“相信表型几分”

最简单的情形：一头动物只有一条自己的记录，其育种值估计约等于 EBV = h² × (表型 − 群体均值)。

表型优势100
估计育种值30
传给后代15

这就是 BLUP 的“收缩”：遗传力越低、信息越少，估计越向均值靠拢。亲属记录越多，估计越准，收缩越小。

05模型档案

所有模型都可以看成从全面模型里挑出几项单独估计、其余并进残差。下面按它主要“拆”的是哪一块来分组。

第一组 · 拆遗传部分 A / D / I

回答：基因的贡献里，哪些能遗传、哪些靠配对。

公畜模型

Sire model
A 的 ¼
y = Xb + Zs + e　　s ~ N(0, Aₛσ²ₛ),　σ²ₛ = ¼σ²A

只给公畜设效应，用后代成绩评价父亲。计算量小，是早期奶牛后裔测定的主力。

优点
方程少、易计算
局限
忽略母亲的遗传贡献和选配，母畜和后代得不到育种值

单性状动物模型

Animal model
A
y = Xb + Za + e　　a ~ N(0, Aσ²A)

每头动物都有育种值，利用父母、后代、同胞等全部亲缘信息。公、母、幼畜在同一尺度上比较。D、I 都被并进残差。

要估的方差
σ²A、σ²e
典型性状
日增重、背膘厚等一生只测一次的性状

加性–显性模型

Additive-dominance model
AD
y = Xb + βF + Za + Zd + e　　a ~ N(0, Aσ²A),　d ~ N(0, Dσ²D)

在动物模型上加一个显性效应 d。近交会让杂合位点变少，显性带来的好处随之减少，表现为近交衰退，所以常同时把近交系数 F 当作协变量放进固定效应。

新增方差
σ²D（显性遗传力 δ² = σ²D/σ²P）
能得到什么
育种值 a 用于选种；a + d 是个体的“总遗传值”，用于预测某个配对后代的表现
数据要求
大量全同胞家系；用 SNP 构建基因组显性矩阵 G_D 效果更好
典型性状
繁殖、存活、产仔数等低遗传力、杂种优势明显的性状

上位效应模型

Epistatic model
ADI
y = Xb + Za + Zd + Z(aa) + Z(ad) + Z(dd) + e
aa ~ N(0, (A⊙A)σ²AA),　ad ~ N(0, (A⊙D)σ²AD),　dd ~ N(0, (D⊙D)σ²DD)

把基因间互作拆成加×加、加×显、显×显等成分，每种用关系矩阵的哈达玛积作协方差。基因组时代常用 G⊙G 这类“基因组上位核矩阵”，也可以换成 RKHS 等核方法。

新增方差
σ²AA、σ²AD、σ²DD
用途
提高个体总遗传值和配对后代的预测；配套系、杂交组合筛选
注意
各成分高度混杂、很难分开，通常只估 σ²AA；需要非常大的数据量

基因组模型 GBLUP / ssGBLUP

Genomic BLUP · Single-step
A → G / H
a ~ N(0, Gσ²A)　或　a ~ N(0, Hσ²A)

公式不变，把谱系算出的 A 换成用 SNP 芯片算出的基因组关系矩阵 G。谱系只给“期望”的亲缘（全同胞都是 0.5），基因组能看到实际分到的基因（可能是 0.42，也可能是 0.58）。一步法 ssGBLUP 用 H 矩阵把有、无基因型的个体一起评估。显性、上位模型也都有对应的基因组版本。

好处
幼畜一出生就有较准的育种值，缩短世代间隔
相关方法
SNP-BLUP、BayesA/B/Cπ、BayesR：假设 SNP 效应分布不同
注意
G 与 A 尺度要对齐；需要足够大的参考群体
第二组 · 拆环境部分 E

回答：哪些环境影响会一直跟着某头动物、某一窝或某个母亲。

重复力模型

Repeatability model
AE: pe
y = Xb + Za + Wpe + e　　pe ~ N(0, Iσ²pe)

同一头母猪生好几窝时，它的记录之间除了基因相同，还有一份一直跟着它的“底子”，这就是永久环境效应 pe，不能遗传。在全面模型里，D 和 I 也会被吸收进 pe，因为它们同样在个体内保持不变。

新增方差
σ²pe
重复力
r = (σ²A + σ²pe) / σ²P，总是 ≥ h²
典型性状
窝产仔数、各胎次产奶量、多次称重
关键假设
各次记录是同一个性状，遗传相关为 1

共同环境（窝效应）模型

Common environment / litter model
AE: c
y = Xb + Za + Wc + e　　c ~ N(0, Iσ²c)

同一窝仔猪共享子宫环境、同一个妈妈的奶水和同一个栏，会比遗传关系预期的更相似。不把窝效应拿出来，全同胞间的这份相似会被误算成遗传，h² 就会偏高。

新增方差
σ²c，c² = σ²c / σ²P
注意
窝效应与显性效应都让全同胞相似，二者容易混杂，需要半同胞或交叉寄养数据来区分

母体效应模型

Maternal effects model
A母体 AE: c
y = Xb + Z₁a + Z₂m + Wc + e　　Var[a; m] = [σ²A σAM; σAM σ²M] ⊗ A

仔猪断奶重不只取决于自己的基因，还取决于妈妈的奶水和带仔能力。妈妈的这种能力本身也可遗传，叫母体遗传效应 m；不可遗传的部分是母体永久环境 c。从仔猪角度看，m 属于“环境”；从妈妈角度看，它是一份育种值。

新增方差
σ²M、σAM（直接与母体的协方差，常为负）、σ²c
总遗传力
h²T = (σ²A + 0.5σ²M + 1.5σAM) / σ²P
典型性状
初生重、断奶重、羔羊早期生长
注意
要有母亲自身的记录，否则 σAM 估不准

基因型×环境互作模型

G×E · reaction norm
AEA×E
多环境：把“环境1的日增重”“环境2的日增重”当两个性状，估遗传相关 rg
反应规范：y = Xb + a₀ + a₁·x + e　　Var[a₀; a₁] = K ⊗ A

好基因在好环境里好，换到热应激猪场就不一定。多环境模型看两个环境里的育种值排名是否一致，rg 低于约 0.8 就说明存在明显的重排。反应规范模型把环境量化成连续变量 x（如温湿指数 THI、猪群平均水平），每头动物有截距 a₀（平均水平）和斜率 a₁（对环境的敏感度）。

新增参数
环境间遗传相关，或截距与斜率的协方差矩阵 K
用途
为不同环境挑适合的种猪；选育耐热、抗逆、稳健的个体

社会遗传效应模型

Indirect genetic effects
直接 A同伴 A
y = Xb + Z_D a_D + Z_S a_S + Wg + e　　Var[a_D; a_S] = [σ²AD σADS; σADS σ²AS] ⊗ A

群养时，一头猪的生长还受同栏猪的影响：爱咬尾、爱抢食的同伴会拖累大家。a_S 是一头猪“对同伴”的遗传效应，对同伴来说是一种环境，但源头是这头猪的基因，所以可以选择。

总育种值
TBV = a_D + (n − 1)·a_S，n 为每栏头数
典型性状
群养猪日增重、咬尾、鸡的啄羽与存活
第三组 · 适配数据形态 P

回答：表型是多个性状、一条曲线、几个类别，还是来自杂交群体。

多性状动物模型

Multi-trait model
A 矩阵化
Var(a) = G₀ ⊗ A,　Var(e) = R₀ ⊗ I

同时分析几个性状。G₀ 是性状间的遗传协方差矩阵，R₀ 是残差协方差矩阵，⊗ 是克罗内克积，把“性状间关系”和“个体间关系”拼在一起。

新增参数
遗传协方差、残差协方差，可算遗传相关 rg
好处
低遗传力性状借助高相关性状提高准确性；能校正选择偏差；是构建选择指数的基础
典型场景
生长与胴体性状联合；多国奶牛联合评估

随机回归模型

Random regression model
A 随时间变pe 随时间变
yₜ = Xb + Σₖ φₖ(t)·aₖ + Σₖ φₖ(t)·peₖ + e

测定日产奶量、生长曲线这类“一条线”的性状，每头动物不再是一个育种值，而是一组回归系数，描述它整条曲线相对群体的偏离。φₖ(t) 常用勒让德多项式或样条。

新增参数
回归系数的协方差矩阵 K（阶数决定曲线的灵活度）
好处
能估计任意时点的育种值和持续力，不用先折算成标准期
典型性状
测定日产奶量、体重曲线、采食量

阈模型

Threshold (liability) model
A潜在尺度
l = Xb + Za + e,　e ~ N(0, 1)　　观测类别 = k，当 tₖ₋₁ < l ≤ tₖ

难产、患病与否、乳头数等级这类“分类别”的性状不是正态的。阈模型假设背后有一个看不见的连续“易感性” l，超过阈值 t 就表现出某一类。模型在 l 的尺度上照常做动物模型。

注意
残差方差固定为 1；常用贝叶斯（吉布斯抽样）或 probit 链接求解
典型性状
难产、乳房炎、仔猪存活、肢蹄评分

杂交与多品种模型

Crossbred / breed-of-origin model
A 分品种杂种优势
y = Xb + h·het + Z_A a_A + Z_B a_B + e　　rpc = 纯种与杂种表现间的遗传相关

商品猪多是杜×长×大三元杂交。纯种核心群里的选择要最终体现在杂种后代身上。模型把杂种优势作为与品种杂合度成比例的固定效应 het，并按等位基因的品种来源（BOA）分别估计各品种的加性效应。

关键参数
rpc 越低，越需要用杂种的表型来选纯种
用途
对应选配路径：挑选最佳杂交组合与配套系

实际工作中常组合使用，比如“多性状 + 母体效应 + 一步法基因组”。但每多一项都要多估方差组分，数据量和结构跟不上时，额外的项会估不准，甚至让模型不收敛。

08和线性代数的联系

所有这些模型最终都要解 Henderson 混合模型方程组（MME）。以基本动物模型为例：

⎡X′X　　X′Z　　　　⎤⎡b̂⎤　⎡X′y⎤
⎣Z′X　　Z′Z + A⁻¹λ⎦⎣â⎦ = ⎣Z′y⎦

λ = σ²e / σ²A = (1 − h²) / h²

每加一个随机效应，系数矩阵就多一行一列的“块”，块的对角上加上它的协方差矩阵的逆乘以方差比：显性加 D⁻¹·σ²e/σ²D，永久环境加 I·σ²e/σ²pe，上位加 (A⊙A)⁻¹·σ²e/σ²AA。

  • 稀疏的逆A⁻¹ 可以按谱系直接写出且非常稀疏，这让百万头动物的评估成为可能；D⁻¹ 和哈达玛积矩阵的逆却是稠密的，这是非加性模型难算的主要原因。
  • λ 是收缩力度遗传力越低 λ 越大，估计越向 0 收缩。
  • ⊗ 克罗内克积把多性状、母体、社会效应的协方差结构组装成大矩阵。
  • ⊙ 哈达玛积两个半正定矩阵的哈达玛积仍是半正定（Schur 积定理），所以 A⊙A 能当协方差矩阵用。
符号约定：σ² 为方差，σ 为协方差；⊗ 为克罗内克积，⊙ 为哈达玛积；A 为谱系加性关系矩阵，D 为显性关系矩阵，G 为基因组关系矩阵，H 为谱系与基因组合并的关系矩阵。示例数值为教学用的简化情形。
