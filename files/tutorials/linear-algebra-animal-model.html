1向量：一支箭头，也是一列数

向量就是"按顺序排好的一串数"。2 个数可以画成平面上的箭头，5 个数虽然画不出来，但规则完全一样。

加法：对应位置相加。几何上就是"箭头首尾相接"。
数乘：2a = (6, 2)，箭头方向不变、长度翻倍。

尺寸规则（最常出错）

(m×n) · (n×p) = m×p。
左边的"列数"必须等于右边的"行数"，中间两个数"抵消"。
例：X(5×2)·b(2×1) = 5×1，正好和 y 一样大。

顺序不能换

一般 AB ≠ BA，甚至 BA 可能尺寸不合根本算不了。几何上：先旋转再拉伸 ≠ 先拉伸再旋转。
但满足结合律：(AB)C = A(BC)。

矩阵乘向量 = 对矩阵的列做加权求和：Xb = b₁·(第 1 列) + b₂·(第 2 列)。这正是"每条记录加上它所属性别的效应"。

6行列式：变换把面积放大了几倍

对 2×2 矩阵，det = ad − bc。几何意义：单位正方形变换后的（有方向的）面积。

  • |det| = 2：面积变 2 倍；det 为负：图形被"翻面"（镜像）。
  • det = 0：平面被压成一条线（或一个点）——信息丢失了，无法还原。回到第 2 节画布点"压扁（奇异）"看看。
  • 高维也一样：3×3 是体积缩放，n×n 是"n 维体积"缩放。

和育种的联系

det = 0 的矩阵叫奇异矩阵，没有逆。MME 左边矩阵如果奇异（比如模型里同时放了总均值和全部性别水平），就需要第 8 节的处理。REML 估计方差组分时还会用到 log|V| 或 log|C|。

三种常见处理

① 去掉一列（如 SAS 把最后一个水平设为 0）；② 加约束（如两性别效应之和为 0）；③ 用广义逆 G（满足 AGA = A）得到一组解。
关键结论：虽然 b̂ 本身不唯一，但可估函数（如"公 − 母"的差）以及育种值 û 的排序是唯一的。所以育种值通常以"相对值"解读。

9方差协方差矩阵：一个"椭圆"

两个随机变量的方差和协方差可以排成对称矩阵 V = [[Var₁, Cov],[Cov, Var₂]]。数据点云的形状就是一个椭圆。

  • Cov = 0：椭圆的轴与坐标轴平行；Cov > 0：向右上倾斜（正相关）。
  • 椭圆的长短轴方向 = 特征向量；轴长² ∝ 特征值。
  • 把 Cov 拉得太大（|Cov| > √(Var₁·Var₂)，即相关系数 |r|>1），就会出现负特征值——这样的"方差矩阵"在现实中不可能存在。

正定矩阵（positive definite）

所有特征值 > 0，等价于对任意非零 x 都有 x′Vx > 0（"任何组合的方差都为正"）。合法的方差协方差矩阵必须正定（或至少半正定）。A、G、R 都应如此；多性状分析中估出的遗传协方差矩阵"不正定"是常见报错，原因往往就是相关系数估出了界。

多性状模型里的克罗内克积 ⊗

两个性状的育种值方差：Var(u) = G₀ ⊗ A。⊗ 的规则：用左边矩阵的每个元素去乘整个右边矩阵，拼成大块。

G₀ = 2 个性状的遗传方差/协方差，A = 2 头半同胞（亲缘 0.5）。结果 4×4 描述"任意两头动物 × 任意两个性状"的协方差。

11从模型推导方差：V、协方差与 BLUP 公式

模型 y = Xb + Zu + e 只写了"均值结构"。把几条假设和三条运算规则用上，就能推出数据的方差结构，进而推出育种值该怎么估。

第 1 步：模型假设（推导的全部"原料"）

假设含义生物学解释
E(u) = 0，E(e) = 0随机效应均值为 0育种值是相对于群体的离差；"平均"部分已放进 Xb
Var(u) = Aσₐ² ＝ G育种值的协方差由亲缘决定只考虑加性效应；亲缘越近，育种值越相像
Var(e) = Iσₑ² ＝ R残差互不相关、方差相同没有共同环境（如同窝效应）；若有，需另加随机效应
Cov(u, e′) = 0遗传与环境无关好基因的牛不会被系统地分到好圈舍
b 固定、σₐ²、σₑ² 已知BLUP 需要先知道方差组分实际中先用 REML 估计（见本节末）

第 2 步：三条运算规则（标量 → 矩阵）

① 期望：线性的

E(Ax + c) = AE(x) + c
标量版：E(ax+c) = aE(x)+c

② 方差："夹心"

Var(Ax) = A·Var(x)·A′
标量版：Var(ax) = a²Var(x)。a² 拆成"左乘 A、右乘 A′"。几何上就是：把第 9 节的椭圆用第 2 节的矩阵 A 变形一下。

③ 和的方差

Var(x+w) = Var(x) + Var(w) + Cov(x,w′) + Cov(w,x′)
Cov(Ax, (Bw)′) = ACov(x,w′)B′

第 3 步：推导

均值：E(y) = Xb + ZE(u) + E(e) = Xb

方差：Xb 是常数，不贡献方差，所以

Var(y) = Var(Zu + e) 　(规则③，Cov(u,e′)=0 两项消失)
= Z·Var(u)·Z′ + Var(e) 　(规则②)
= ZAZ′σₐ² + Iσₑ² ＝ V

记录与育种值的协方差：

Cov(y, u′) = Cov(Zu + e, u′) = Z·Var(u) = ZAσₐ²

第 4 步：从方差到"最好的预测"

已知 y 后，怎样猜 u 最准？统计上的答案是条件期望。在正态假设下，它是一条回归：

û = Cov(u, y′) · Var(y)−1 · (y − E(y)) = GZ′V−1(y − Xb̂)

其中 b̂ 用广义最小二乘（GLS）估计：b̂ = (X′V−1X)−1X′V−1y。V−1 就像"权重"：方差大、彼此相关的记录被打折。

标量直觉：只有自身一条记录时

所有矩阵都变成数：G = σₐ²，Z = 1，V = σₚ²，于是
û = (σₐ² / σₚ²)(y − μ) = h²(y − μ)
这就是经典的"育种值 = 遗传力 × 表型离差"。回归系数 = 协方差 / 方差。矩阵版 GZ′V−1 只是把它推广到"多条记录、亲属互相借信息"的情况。拖动滑块看：点是模拟的个体，横轴表型离差，纵轴真实育种值。
红色虚线：斜率 1，直接拿表型当育种值。
绿色实线：斜率 h²，即 BLUP 的"收缩"预测，离差平方和最小。
h² 越低，点云越扁平，最佳预测线越平——证据少，就越保守。

第 5 步：预测有多准——PEV 与可靠性

预测误差 u − û 的方差（PEV）可以直接从 MME 左边矩阵的逆 C−1 读出：

Var(ui − ûi) = ciiσₑ²，　　r²i = 1 − PEVi / (aiiσₐ²)，　　SEP = √PEV

其中 cii 是 C−1 里动物 i 对应的对角元。还有两个常用结论：Var(û) = Cov(u, û′) = G − PEV（估计值的方差比真实育种值小，也就是"收缩"），以及 r² = Var(ûi)/Var(ui)。

附：σₐ²、σₑ² 本身怎么来？（REML 一瞥）

以上都假设方差组分已知。实际中先用 REML（约束最大似然）估计：它去掉固定效应 b 的影响，再让数据出现的"可能性"最大。其对数似然为
log L = −½ [ log|V| + log|X′V−1X| + y′Py ] + 常数，　P = V−1 − V−1X(X′V−1X)−1X′V−1
这里用到了行列式（第 6 节）、逆（第 7 节）。EM-REML 的迭代式更直观（q 为动物数，Cuu 为 C−1 中育种值那一块）：
σ̂ₐ² = [ û′A−1û + tr(A−1Cuu)σₑ² ] / q
直观上：第一项是"估出来的育种值有多分散"，第二项把预测误差补回来，因为 û 被收缩了。这里又出现了迹 tr（对角线之和）。
